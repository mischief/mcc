# C17 conformance

mcc checked against the working draft N2310 (C17 with the first C2x
changes), on amd64, i386, arm64 and riscv64, with gcc -std=c17 as the
reference.  mcc accepts GNU C on purpose; GNU extensions are not listed
as departures.

Status: conforms, partial, missing, wrong.  A test named `cNN` is a case
in test/c run by test/cc.lua on every target.
